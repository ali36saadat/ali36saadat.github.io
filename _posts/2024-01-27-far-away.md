## Description
This project is related to section 6 of [Jonas's React course](https://www.udemy.com/course/the-ultimate-react-course/), focusing on working with the state, events and forms. This is an application where you can list the items needed for a trip and checkmark them.

## Usage
**Requirements:** `node` and `npm`

1: Clone
```bash
git clone https://github.com/ali36saadat/far-away.git
cd far-away
```
2: Install Dependencies
```bash
npm install
```
3: Run
```bash
npm start
```
