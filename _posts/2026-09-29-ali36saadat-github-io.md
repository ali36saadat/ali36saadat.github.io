## Usage
**Requirements:** `ruby` 3.0.0 or higher, GCC and Make (check versions using `gcc -v`,`g++ -v`, and `make -v`)

1: Clone
```bash
git clone https://github.com/ali36saadat/ali36saadat.github.io.git
cd ali36saadat.github.io
```
2: Install the Jekyll and bundler Gems
```
bundle install
```
or
```
gem install jekyll bundler
```
3: Run Jekyll
```
bundle exec jekyll serve
```
4: Browse to [http://localhost:4000](http://localhost:4000) ( or [http://127.0.0.1:4000](http://127.0.0.1:4000) )
