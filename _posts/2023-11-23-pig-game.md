### Description
This project is related to section 7 of [Jonas's course](https://www.udemy.com/course/the-complete-javascript-course), focusing on working with the Document Object Model (DOM). Additionally, it include one exciting extra game mode. you can play with BOT, definitely give it a try

### Usage
**Requirements:** None ( but running with [`live-server`](https://www.npmjs.com/package/live-server) is recommended )

1: Clone
```bash
git clone https://github.com/ali36saadat/pig-game
cd pig-game
```
2: Run
```bash
live-server
```
or
```bash
npx live-server
```
