## Description
This project is related to section 11 and 12 of [Jonas's course](https://www.udemy.com/course/the-complete-javascript-course), focusing on working with arrays, array methods, dates, Intl date . Additionally, it includes sign in form.

## Usage
**Requirements:** None ( but [`live-server`](https://www.npmjs.com/package/live-server) is recommended )

1: Clone
```bash
git clone https://github.com/ali36saadat/bankist.git
cd bankist
```
2: Run
```bash
live-server
```
or
```bash
npx live-server
```
