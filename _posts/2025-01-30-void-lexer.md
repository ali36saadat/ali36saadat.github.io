### Description
Void Lexer is a desktop lexical-analyzer project for C++, built with Angular and Electron. It brings a web-based interface together with a desktop shell to inspect C++ source code through lexical analysis.

### Usage
**Requirements:** `node` 21.5.0 or higher, `npm` 10.8.3 or higher

1: Clone
```bash
git clone https://github.com/ali36saadat/void-lexer.git
cd void-lexer
```
2: Install Dependencies
```bash
npm install
```
3: Run in development mode
```bash
npm run dev
```
